# Visual asset sources

This project keeps the visual assets local so the app works offline and does not depend on a remote image host.

- The utility and navigation glyphs are Android Vector Drawable adaptations of the open-source [Material Design Icons](https://github.com/google/material-design-icons) collection. The collection is distributed under the Apache License 2.0.
- The supplied `home_action_*.png` and `home_service_*.png` assets are transparent crops of the corresponding icons from the user-provided home-screen reference. They preserve the reference artwork while the surrounding cards remain native XML.
- The card and tile backgrounds are native Android shape drawables defined in `app/src/main/res/drawable`, rather than raster images. That keeps their corners and spacing crisp at every screen density.
- `avatar_reference.jpg`, `claim_reference.png`, and `gift_reference.png` are density-neutral crops from the user-supplied reference screenshot in `screenshots/`. The claim and gift crops use transparent masks so they also blend correctly in the dark theme. The provider/logo crops (`recipient_*.png` and `bank_logo_*.png`) are similarly taken from the supplied To Bank reference so recent recipients and frequently used banks remain visually accurate even before network logos finish loading.
- `ic_cashbox.xml` and `ic_fixed_savings.xml` are small, original vector illustrations created for this clone and are not copied from the PalmPay application.
- The `exact_*.png` assets in `drawable-nodpi` are the exact supplied icons wired in from the user-provided density dumps at the repository root (`drawable-mdpi/`, `drawable-xhdpi/`, `drawable-xxhdpi/`, `drawable-night-xxhdpi/`). `exact_action_bank` and `exact_coins` are the official `mm_icon_bank` / `mm_icon_upgrade` glyphs with their baked background discs removed; `exact_clear_circle` is `app_assets_img_input_clear_gray`; `exact_check_circle` is `cv_check_green`. The bottom-nav, headset, bell, eye and shield glyphs exist only as compiled vectors inside the source APK (not present in the raster dump), so `exact_nav_*`, `exact_headset`, `exact_bell`, `exact_eye_visible` and `exact_shield_check` are transparent alpha masks traced from the reference screenshots; the existing theme tints (`@color/ink`, nav selector, `icon_green`, `transfer_green`, `brand_purple`) recolor them for light/dark parity.
- The screen content and naming are based on the public PalmPay product reference at [palmpay.com](https://palmpay.com/). This repository does not bundle PalmPay-owned logos, photographs, or proprietary artwork.
- The bank picker loads the broad Nigerian bank/logo directory from the public [Nigeria Banks Logo API](https://github.com/jsanwo64/Nigeria-Banks-Logo-API), using its JSON endpoint at `https://jsanwo64.github.io/Nigeria-Banks-Logo-API/Banks.json`. It falls back to a local directory when offline, and only accepts HTTPS logo URLs.

The implementation is intentionally Java + XML: the XML layouts define the reusable visual components, while `HomeCatalog` supplies immutable models and `HomeScreenController` binds them and handles interactions.
